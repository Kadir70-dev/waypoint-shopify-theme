Predictive search — local DOM/event-flow test

Loads the real overlay.js and predictive-search.js files unmodified. window.fetch is intercepted ONLY to stand in for the live Shopify Predictive Search API response (network calls aren't available in this environment) — every DOM attribute, debounce timer, abort, and keyboard handler below is the real, unmodified code path. This proves the client-side logic; it does NOT prove the live API integration. Wait margins below are generous (1.2–1.5s) because Chrome throttles timers heavily in backgrounded/automation-driven tabs — on a normal focused tab this all resolves in well under 300ms, matching the 180ms debounce + ~40ms mock network delay.
